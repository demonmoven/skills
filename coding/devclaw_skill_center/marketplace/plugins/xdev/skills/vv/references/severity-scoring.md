# 严重程度与评分标准（Severity & Scoring）

本文件定义 V&V 审查系统的统一严重程度分级、中英文映射和评分公式。

---

## 1. 四级严重程度定义

| 中文 | 英文 | 标记 | 描述 |
|------|------|------|------|
| **严重** | critical | `[REQUIRED]` | 必须在代码合入前修复的严重问题（bug、安全漏洞、兼容性破坏、严重违反规范） |
| **中等** | high | `[RECOMMENDED]` | 强烈建议修复的设计缺陷或不佳实践 |
| **轻微** | medium | `[OPTIONAL]` | 可讨论的改进点，不应阻塞代码合入 |
| **提示** | low | `[NOTICE]` | 不确定是否是问题，或优先级很低的观察 |

---

## 2. 中英文映射表

LLM 审查 skill 使用中文四级名称输出，summary.json / verdict.json 使用英文名称：

| 中文输出 | JSON 字段值 | 扣分权重（LLM 模式） | 扣分权重（门禁模式） |
|----------|------------|---------------------|---------------------|
| 严重 | `critical` | -25 | -25 |
| 中等 | `high` | -10 | -10 |
| 轻微 | `medium` | -3 | -5 |
| 提示 | `low` | 0 | 0 |

---

## 3. 评分公式

### LLM 审查模式（所有 LLM review skill + conclusion + mock-detection）

基础分 100 分，按发现的问题扣分：

| 问题级别 | 扣分 |
|----------|------|
| 严重 (critical) | 每个 -25 分 |
| 中等 (high) | 每个 -10 分 |
| 轻微 (medium) | 每个 -3 分 |
| 提示 (low) | 每个 -0 分（不扣分，仅记录） |

最低分为 0 分。

### 确定性/门禁模式（rule-precheck, pr-gate, agents）

基础分 100 分：

| 问题级别 | 扣分 |
|----------|------|
| critical | 每个 -25 分 |
| high | 每个 -10 分 |
| medium | 每个 -5 分 |
| low | 每个 -0 分 |

最低 0 分。

> **注意**：门禁模式的 medium 扣 5 分（而非 LLM 模式的 3 分），因为门禁检测的 medium 问题通常更具确定性。

---

## 4. Pass/Fail 标准

### LLM 审查标准

**通过 (Pass)** 需要同时满足：
1. **无严重问题**: 严重问题数量 = 0
2. **无中等问题**: 中等问题数量 = 0
3. **无轻微问题**: 轻微问题数量 = 0
4. 各 skill 特定的额外条件（如无安全漏洞、无 Breaking Change 等）

**不通过 (Fail)**: 存在任何严重、中等或轻微问题。

**提示级别问题不影响 Pass/Fail 判定。**

### 门禁标准（按 GATE_LEVEL）

| 门禁级别 | Pass 条件 |
|----------|----------|
| PR | score >= 70, 零 critical |
| Nightly | score >= 80, 零 critical, 零 high |
| Release | score >= 90, 零 critical, 零 high, 零 medium |

---

## 5. 评分计算公式（供报告使用）

### LLM 审查模式

```
基础分: 100
严重问题扣分: -{X * 25}
中等问题扣分: -{Y * 10}
轻微问题扣分: -{Z * 3}
提示扣分: -0（不扣分）
最终得分: max(0, 100 - X*25 - Y*10 - Z*3)
```

### 确定性/门禁模式

```
基础分: 100
严重问题扣分: -{X * 25}
中等问题扣分: -{Y * 10}
轻微问题扣分: -{Z * 5}
提示扣分: -0（不扣分）
最终得分: max(0, 100 - X*25 - Y*10 - Z*5)
```

> **注意**：门禁模式的 medium 扣 5 分（而非 LLM 模式的 3 分），因为门禁检测的 medium 问题通常更具确定性。
