# 输出模板（Output Template）

本文件定义所有 LLM 审查 skill 的标准报告输出格式。

---

## 1. 报告头部

```markdown
# {报告标题}

## 审查摘要

- **审查时间**: {timestamp}
- **迭代轮次**: {{iteration}}/{{maxIterations}}
- **审查范围**: {审查范围描述}
```

---

## 2. 检查项统计表

```markdown
## 检查项统计

| 检查类别 | 问题数 |
|----------|--------|
| {类别1} | {count} |
| {类别2} | {count} |
```

---

## 3. 文件审查结果表

```markdown
## 文件审查结果

| 文件 | 状态 | 主要问题 |
|------|------|----------|
| {file1.go} | ✅ 良好 / ⚠️ 有问题 / ❌ 严重问题 | {备注} |
```

---

## 4. 发现条目格式

```markdown
## 发现的问题

### 问题 {N}: {标题}
- **严重程度**: 严重 / 中等 / 轻微 / 提示
- **文件**: `{路径}:{行号}`
- **类别**: {类别标签}
- **问题描述**: {描述}
- **证据**:
  ```go
  {代码片段}
  ```
- **不确定原因**: {仅当严重程度为"提示"时填写：为什么不确定是否是问题}
- **建议**:
  ```go
  {修复方法}
  ```
```

---

## 5. 评分与结论节

```markdown
## 评分与结论

**⚠️ 重要说明：不要使用"只有轻微问题"、"可以通过 review"、"问题不严重"等淡化问题的描述！**
**如果发现任何问题（无论级别），都必须明确强调"存在问题，需要修复"！**

### 问题统计
- 严重问题: {X} 个
- 中等问题: {Y} 个
- 轻微问题: {Z} 个
- 提示: {W} 个

### 分数计算
- 基础分: 100
- 严重问题扣分: -{X * 25}
- 中等问题扣分: -{Y * 10}
- 轻微问题扣分: -{Z * 3}
- 提示扣分: -0（不扣分）
- **最终得分: {score}**

### 通过判定
- 严重问题数量: {X} (要求: 0)
- {skill 特定的额外判定条件}
- **结论: {PASS/FAIL}**
- **原因: {如果 FAIL，说明原因}**

<score>{0-100}</score>
<pass>{true/false}</pass>
```

---

## 6. 反淡化警告

所有报告**必须**在评分与结论节开头包含以下警告：

> **⚠️ 重要说明：不要使用"只有轻微问题"、"可以通过 review"、"问题不严重"等淡化问题的描述！**
> **如果发现任何问题（无论级别），都必须明确强调"存在问题，需要修复"！**

---

## 7. 中文输出要求

**所有输出内容必须使用中文！** 包括但不限于：
- 问题描述
- 修复建议
- 风险提示
- 备注说明
- 审查摘要与结论

仅以下内容可保留英文：
- 代码片段
- 文件路径和行号
- 专有技术术语（如 `context.Context`, `sync.Mutex` 等）

---

## 8. XML 标签约定

报告结尾**必须**包含以下 XML 标签，用于机器解析：

- `<score>{0-100}</score>` — 最终得分
- `<pass>{true/false}</pass>` — 是否通过
