## 六、典型协作动线（举例）

### 例 1：新增一个文生图工具（如水印工具）

```
1. PM 对齐：欧桐桐
2. 智创工程评估接入：徐鑫团队
3. 模型算法侧支持（如有）：王明轩 / 林泽发
4. 安全侧确认（特别是新模型）：曹东欧 / 蒋星
5. 灰度策略：汤昱文
```

### 例 2：分身写真新增一个训练参数

```
1. PM 对齐：陈思颖
2. 模型工程：刘舒帆 / 杨启凡
3. 智创工程：徐鑫
4. 安全机审：（画风机审 PM，见画板）
```
