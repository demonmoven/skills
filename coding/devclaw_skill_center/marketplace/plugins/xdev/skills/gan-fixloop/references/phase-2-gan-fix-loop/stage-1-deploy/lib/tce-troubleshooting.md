# 常见问题排查

## 1. 部署超时（20 分钟无 Running 实例）

**原因**：TCE 构建慢、镜像拉取慢、资源不足等。

**解决**：
- 查询实例状态，查看是否有错误信息
- 登录 TCE 控制台查看部署状态和构建日志
- 确认分支名和仓库地址正确
- 首次部署通常需要 5-10 分钟，耐心等待

## 2. 泳道实例状态异常

**常见实例状态**（bytedcli 可能返回中文或英文，取决于版本和 locale，两种都要匹配）：

| 英文状态 | 中文状态 | 说明 | 处理 |
|---------|---------|------|------|
| `Running` | `运行中` | 实例就绪 | 部署成功 |
| `Pending` | `待处理` | 等待调度 | 继续等待 |
| `Creating` | `创建中` | 正在创建 | 继续等待 |
| `Building` | `构建中` | 正在构建镜像 | 继续等待 |
| `Restarting` | `重启中` | 重启中 | 继续等待，关注是否反复重启 |
| `Failed` | `失败` | 启动失败 | 查看日志排查原因 |

> **容错提醒**：匹配状态时务必同时检测中英文，使用 `grep -E "Running|运行中"` 而非单独匹配某一种。

## 3. 部署命令返回成功但实例一直不出现

**原因**：deploy-lane 只是触发部署流程，实际构建和部署由 TCE 平台异步执行。

**解决**：
- 耐心等待，首次部署需要 5-10 分钟
- 到 TCE 控制台查看部署流水线状态
- 确认标准环境和 SCM 基线参数正确
