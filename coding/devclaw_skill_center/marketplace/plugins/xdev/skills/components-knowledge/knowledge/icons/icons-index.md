# Coze Design 图标列表

所有图标从 `@coze-arch/coze-design/icons` 引入。

```tsx
import { IconCozEdit, IconCozPeopleFill } from '@coze-arch/coze-design/icons';

<IconCozEdit />
<IconCozPeopleFill className="text-xxl coz-fg-hglt" />
<IconCozPeopleFill style={{ fontSize: '24px', color: '#6001D3' }} />
```

## 图标命名规则

- 基础图标：`IconCoz{Name}`（如 `IconCozEdit`）
- 填充变体：`IconCoz{Name}Fill`（如 `IconCozEditFill`）— 实心填充风格
- Palette 变体：`IconCoz{Name}FillPalette`（如 `IconCozCrossCircleFillPalette`）— 多色填充风格
- Slash 变体：`IconCoz{Name}Slash`（如 `IconCozLinkSlash`）— 禁用/关闭状态
