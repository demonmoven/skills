# Knowledge Gaps

AI 初始化时识别但无法完全确定的知识缺口。
按优先级排列，建议在日常开发中逐步补充。

**处理流程**：
1. 日常开发中遇到相关知识时，更新对应文档并关闭缺口
2. 每月 review 一次高优先级缺口
3. 关闭缺口时标注解决方式和日期
