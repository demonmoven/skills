# 3.2.2 UI 还原

> **本节目标**：理解 UI 还原在 Agent 工作流中的位置——前端代码改完不等于视觉对，需要从设计稿到实现的全链路校验与自动修复。

---

## 概念

**UI 还原**验证前端实现与设计稿的视觉一致性。Agent 改完前端代码后需要自动验证"看起来对不对"，并在偏差处自动修复。

从 Figma 设计稿到代码实现的全链路包括：

1. **设计稿解析**——提取结构和视觉规格
2. **代码生成**——业务组件 + 页面代码
3. **还原度校验**——对比实现与设计稿
4. **偏差自动修复**——按设计稿修改实现

---

| **x-ui-workflow** | Figma 设计稿 → 代码 → 还原度校验 | UI 实现与设计稿的一致性验证 |

## x-ui-workflow

> **核心思想**：从 Figma 设计稿到代码实现的全链路——不只是"生成代码"，还包括还原度校验和自动修复。

### Slash Command

| 命令 | 说明 | 产物 |
|------|------|------|
| `/xdev:x-ui-workflow /design-from-figma <page_name> <figma_url>` | **推荐入口**——全流程串联 + 生成组件文档 | 组件代码 + `component-design.md` |
| `/xdev:x-ui-workflow /ui-analyze <page_name> <figma_url>` | 获取设计稿截图 + 高保真 JSX | 设计截图 + JSX 代码 |
| `/xdev:x-ui-workflow /ui-structure <page_name> <figma_url> <image> <jsx>` | UI 结构分析 | `ui.xml` + `ui.implement.xml` + `ui.md` + `nodes/` |
| `/xdev:x-ui-workflow /ui-coding <page_name>` | 生成 UI 代码 | 业务组件代码 + 页面代码 |
| `/xdev:x-ui-workflow /ui-structure-and-coding <page_name> <figma_url> <image> <jsx>` | 结构分析 + 代码生成（高效模式） | 组件代码 + 页面代码 |
| `/xdev:x-ui-workflow /ui-fix "<描述>" <figma_url> <target_dir>` | **还原度修复**——按设计稿修复现有代码 | 修改后的代码文件 |
| `/xdev:x-ui-workflow /ui-fix-batch <page_name>` | **批量并行校验**所有组件还原度 | 批量修复的代码文件 |
| `/xdev:x-ui-workflow /design-from-directory <reference_dir>` | 从已有目录补齐组件文档 | `component-design.md` |

### 工作流

两种管线模式：

```text
高效模式（推荐）：
  /ui-analyze → /ui-structure-and-coding → component-design.md
                                              ↓
                                     /ui-fix-batch（批量校验还原度）

分步模式：
  /ui-analyze → /ui-structure → /ui-coding → /ui-fix-batch
```

> **前置条件**：需设置 `FIGMA_ACCESS_TOKEN` 环境变量。

### 中间产物

> **核心思想**：每一步产出明确的中间文件，支持断点续传和单步调试。

```text
{page_name}/
├── design-screenshot.png     # /ui-analyze 产出：设计稿截图
├── high-fidelity.jsx         # /ui-analyze 产出：高保真 JSX
├── ui.xml                    # /ui-structure 产出：UI 结构树
├── ui.implement.xml          # /ui-structure 产出：实现结构树
├── ui.md                     # /ui-structure 产出：结构说明文档
├── nodes/                    # /ui-structure 产出：组件节点详情
├── components/               # /ui-coding 产出：业务组件代码
├── page.tsx                  # /ui-coding 产出：页面代码
└── component-design.md       # /design-from-figma 产出：组件设计文档
```
