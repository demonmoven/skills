# 2.5 流程控制

> **本节目标**：理解 Agent 执行流程如何被编排和约束——用 SubAgent 分解任务，用 Hooks 建立质量门禁。

---

## 概念

**流程控制**回答的是 "Agent 怎么干活"——任务如何分解、如何并行、如何在关键节点设置检查点。

如果说上下文控制管的是 Agent 的"输入质量"，流程控制管的就是 Agent 的"执行路径"和"输出质量"。

```text
上下文控制 ──→ Agent 看到正确的信息
流程控制   ──→ Agent 按正确的步骤执行
                └──→ 关键节点自动检查（Hooks）
                └──→ 复杂任务自动分解（SubAgent）
```

---

## 流程控制的两大手段

| 手段 | 作用 | 类比 |
|------|------|------|
| **SubAgent** | 任务分解与并行执行 | 项目经理把大任务拆给多个团队成员 |
| **Hooks** | 关键节点的自动检查 | CI/CD 流水线上的质量门禁 |
