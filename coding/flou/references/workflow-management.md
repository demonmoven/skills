# 流程管理

管理流程的创建、验证和维护。

## 流程创建

详见 [workflow_specification_rules.md](../statics/workflow_specification_rules.md)

支持用户用自然语言表达流程，自动生成流程文件：

1. **自然语言解析**：识别意图、步骤、分支、循环结构
2. **结构化转换**：生成符合规范的流程文件
3. **完整性检查**：自动识别缺失的门禁、描述不清
4. **引导补充**：对不完整流程引导用户补充

## 流程加载

### 加载优先级

1. **项目流程**：记忆系统检索到项目流程，优先使用
2. **用户指定**：用户明确指定流程模式时使用指定流程
3. **默认流程**：默认使用 SDD 流程

### 加载流程

```
用户启动任务
    ↓
检查项目流程 → 存在？ → 是 → 加载项目流程
    ↓ 否
用户指定流程？ → 是 → 加载指定流程
    ↓ 否
加载默认流程（SDD）
```

### 项目流程目录

```
$FLOU_DIR/memory/flows/
├── code_review_flow.md    # 代码评审流程
├── deploy_flow.md         # 部署流程
└── *.md                   # 其他自定义流程
```

## 流程归档

### 归档规则

项目流程创建后，使用 `flou-cli` 归档到记忆系统：

```bash
# 归档流程文件
flou-cli memory \
  add "流程简介:代码评审流程, 文件地址:$FLOU_DIR/memory/flows/code_review_flow.md"
```

### 归档要求

- **必须标签**：`项目流程`（用于检索过滤）
- **可选标签**：根据流程内容添加，如 `开发`、`测试`、`部署` 等
