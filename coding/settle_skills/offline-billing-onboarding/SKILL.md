# 离线计费接入实时答疑

回答离线计费接入问题时，必须以指定飞书文档的实时最新内容为准，不能依赖静态知识库、历史回答或记忆中的口径。

## 强制实时读取规则

每次触发本 Skill 后，回答用户问题前必须完成以下动作：

1. 使用 `lark-doc` skill 实时读取以下两篇飞书文档：
   - 文档 1（Wiki）：https://bytedance.larkoffice.com/wiki/XbaYwI9boiyXEbktGNYcGLFDnne
   - 文档 2（Docx）：https://bytedance.larkoffice.com/docx/FcZrdDL3SoPqSox4HmVc7IT7ngb
2. 如果下载后的文档中包含飞书画板、图片或其他嵌入内容，按 `lark-doc` skill 的读取要求继续读取相关嵌入内容。
3. 只基于本次实时读取到的最新内容回答用户问题。
4. 不得使用静态知识库、历史回答、记忆中的内容或旧版 System Prompt 作为事实来源。
5. 如果两篇实时文档内容互相冲突，说明“当前两篇文档口径不一致”，并分别列出冲突点；不要自行合并或猜测。
6. 如果飞书文档读取失败，不要凭旧知识回答；应明确说明读取失败，并提示需要恢复文档访问或稍后重试。

## 回答方式

读取完成后，按用户问题从最新文档中提取相关信息，简洁回答：

1. **结论**：直接回答能不能做、应该怎么做、字段怎么填。
2. **依据**：说明来自实时读取文档中的哪类内容，例如“接入 SOP”“字段说明”“注意事项”。
3. **下一步**：如需补充业务信息、找资金运营配置、找计费技术核对，则明确说明。

对字段、表名、金额单位、分区、方向、写入时效等强口径问题，必须以实时读取内容为准。

如果问题涉及新增规则、`properties` 字段设计、计费因子或特殊业务场景，只有当实时文档中明确要求评审时，才提醒对应评审要求。

如果实时文档未覆盖用户问题，直接说明“当前两篇文档未说明该问题”，并建议找计费技术或资金运营确认。

## 禁止事项

- 禁止直接引用静态知识库回答。
- 禁止在未读取飞书文档的情况下回答具体口径。
- 禁止编造文档中不存在的表、字段、流程、负责人、时间要求或系统能力。
- 禁止把历史版本内容当作最新结论。
