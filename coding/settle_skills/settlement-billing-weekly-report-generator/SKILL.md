# 结算计费周报生成器 (Settlement Billing Weekly Report Generator)

本 Skill 旨在自动化生成“结算计费值班周报”，包括对报警消息的归因分析以及对账差异的原因总结。

## 触发场景

- 用户要求生成结算计费周报。
- 周报的值班周期为本周值班期间（上周四 00:00 至 下周三 23:59）。

## 核心流程

### Stage 1: 时间范围计算
- 运行 python3 scripts/calculate_time.py 获取本周值班的开始和结束日期。
- **注意**：日期格式用于文档标题和表格表头。

### Stage 2: 聊天消息抓取与分析
针对以下三个核心群组，使用 mcp:lark_chat_history_lark_chat_history 工具抓取 Stage 1 时间范围内的聊天记录：

1. **监控报警（群组 1 & 2）**：
   - 群组 1：`追光结算计费产研报警群` (ID: `oc_383f8568195000b2fc65e8a36389a87b`)
   - 群组 2：`【P0】追光计费结算报警群` (ID: `oc_177aaa2b60e37efec448b39e711cd8f1`)
   - **分析逻辑**：提取报警卡片（如 Argos 报警），并结合其后的 Thread 讨论或紧跟的回复内容，归纳出该报警的“报警原因”。如果没找到原因，标记为“排查中”。

2. **核对报警（群组 3）**：
   - 群组 3：`结算内部对账报警群` (ID: `oc_d3e9e609cd082fffe0b69fd8e8c623f5`)
   - **分析逻辑**：提取核对差异卡片（如对账失败、差异报警），结合讨论归纳“差异根因”。

### Stage 3: 文档生成与格式对齐
- 创建一个新的飞书文档。
- **标题格式**：`结算计费周报（开始日期～结束日期值班记录）`。
- **文档结构**：
  - **第一部分：监控报警**：包含一个 HTML 表格（`<table>`），字段为「告警内容+链接」和「报警原因」。
  - **第二部分：核对**：包含一个 HTML 表格（`<table>`），字段为「差异名称」和「差异根因」。
- **格式要求（严格对齐）**：
  - 使用 HTML `<table>` 语法（严禁使用管道符 Markdown 表格）。
  - 表头列宽设置：`col-widths="500,500"`。
  - 第一列内容需带原文跳转链接（例如：`[告警文本](原文链接)`）。

## 关键约束
1. **时间过滤**：必须确保消息抓取覆盖 Stage 1 算出的完整周期。
2. **原因归纳**：
   - 必须通过上下文（尤其是 Thread 回复）寻找结论性发言。
   - 如果群里只有报警没有结论，请根据报警卡片本身的 PSM 或报错信息，简要推断可能的模块或直接标记“排查中”。
3. **格式一致性**：参考 references/template.lark.md 的 HTML 表格结构。

## MCP 依赖
- **lark_chat_history**：用于获取群聊消息。
- **lark**：用于创建文档。
