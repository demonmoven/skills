# PRD 资金流图

## 目的

为技术方案的 `资金流分析` 章节生成账户级资金流图和分析。输出必须说明每个业务动作下哪个主体、哪个账户借记/贷记，并映射到 PRD 意图和代码证据。

## 输入

- `prd2tech/<需求目录>/prd-understand.md` 中的资金/账务描述和业务场景。
- `prd2tech/<需求目录>/prd-feature-split.md` 中带资金流影响的功能点矩阵。
- `prd2tech/<需求目录>/investigation.md` 中的 Wiki 线索和代码证据。
- 账户决策、fund clause 生成、biz code、fund-driven type、settlement-driven type、幂等相关代码证据。
- 历史方案/Wiki 只作为定位上下文；最终事实由 PRD 和代码决定。

资金流不确定点属于阻塞条件。任何重要账户、路径、金额或时点问题无法从 PRD 或代码确认时，必须停止并询问用户，不能直接定稿。

## 本地产物

- 输出必须写入 `prd2tech/<需求目录>/funds-flow-diagram.md`。
- 如果用户微调了 `prd-understand.md`、`prd-feature-split.md` 或 `investigation.md` 后重跑，必须基于最新本地文件重新分析资金流和信息流字段链路。
- 技术方案生成阶段直接读取 `funds-flow-diagram.md`，因此本文件中的资金流图、动作矩阵、字段链路和证据说明必须可直接粘贴进方案正文。

## 必须分析的维度

对每个真实动账或生成账务/明细的动作，必须识别：

- 动作：业务动作和系统动作，例如 consult、confirm、refund、charge、结算明细生成、汇总、凭证、补偿、冲正。
- 主体：用户、商户、平台、服务商、机构、财务主体、内部清分主体。
- 账户：待结算户、现金户、垫资户、手续费户、分账接收方账户、机构户、中间户，或代码中的明确账户常量。
- 方向：借记、贷记、冻结、解冻、仅生成明细、不真实动账。
- 金额来源：PRD 字段/API 字段/代码字段、金额类型、币种、手续费/退款本金/补差等口径。
- 证据：PRD 章节 + 代码文件/函数/配置/常量；未确认时标记 `待确认`。
- 边界：该阶段是仅生成明细、触发汇总、生成凭证/账务、调用 fund service，还是仅模拟/补齐资金平衡。

## 工作流程

1. 构建资金动作矩阵：

| 动作 | 触发条件 | 主体 | 借方账户 | 贷方账户 | 金额来源 | 是否真实动账 | biz code/fund type | 证据 | 结论 |
| --- | --- | --- | --- | --- | --- | --- | --- | --- | --- |

2. 账户行为不同的场景要分图展示。标准退款、指定账户退款、周期结算、补充结算、扣费等账户路径不同的场景不要合并。
3. 使用 Mermaid flowchart 绘制账户级节点：
   - 节点用 `主体::账户` 标注，例如 `商户::待结算户`、`商户::现金户`、`平台::垫资户`。
   - 边上标注动作、金额、方向、biz code/fund-driven type 和 diff 标记。
   - 分支节点表达 PRD/配置/代码中的账户决策条件。
4. 按需填充技术方案中的三类资金流：
   - `记账资金流`：平台账务/明细/会计方向。
   - `机构记账资金流`：机构侧或渠道侧记账。
   - `机构实体资金流`：机构/渠道真实资金流转。
   不涉及时写 `不涉及，原因：...`。
5. 补充每个动作的文字说明：
   - 说明该动作下哪个主体/账户发生变化。
   - 区分明细生成、汇总、凭证、真实资金划转。
   - 说明未变化的既有逻辑和本次新增逻辑。
6. 与信息流配套：
   - 返回 `信息流分析` 所需字段：来源字段、决策字段、持久化字段/表、下游字段/消息。

## 输出格式

写入 `prd2tech/<需求目录>/funds-flow-diagram.md`，内容应可直接粘贴进技术方案：

````markdown
#### <场景名称>资金流图

```mermaid
flowchart LR
    A[商户::待结算户]
    B[商户::现金户]
    C[平台::垫资户]
    D{账户决策条件}

    D -- <条件 + 证据> --> A
    A -- \"+ <动作>/<金额>/<biz code>\" --> C
    C -- \"~ <动作>/<金额>/<fund type>\" --> B
```

| 动作 | 主体 | 借方账户 | 贷方账户 | 金额来源 | 是否真实动账 | biz code/fund type | 代码证据 | 说明 |
| --- | --- | --- | --- | --- | --- | --- | --- | --- |
|  |  | 待结算户/现金户/垫资户/... |  | PRD/API/代码字段 | 是/否，仅生成明细 |  |  |  |

| 信息字段 | 来源 | 决策/派生 | 持久化 | 下游传递 | 兼容性 |
| --- | --- | --- | --- | --- | --- |
|  | PRD/API/消息/配置 |  | 表/字段/状态 | RPC/MQ/回调/离线 |  |
````

## 质量要求

- 不得只依据 Wiki 回答账户流转。
- 需要区分 `待结算户`、`现金户`、`垫资户` 时，不得笼统写成 `商户账户`。
- 不要把不确定点藏在正文里。重要账户、主体、金额、时点不确定时必须阻塞确认。
- 不要把资金流和信息流混成一张图；先生成账户流转，再生成字段链路。
